# 共通カード裏面

2026-10-19採用: 黒地・中央タイトルロゴ・細い金枠。支給された採用画像をそのまま使用し、ロゴの描き直しや他案への置き換えは行わない。

- 原本: `output/card-back-approved-20261019/original.png`
- 規格: 横300:縦470、900×1410px、周囲透過、内側は黒。
- 共通配信画像: `public/assets/cards/card-back-v1.webp`（ロスレス）。
- 加工: 透明余白の整理と等倍比率のサイズ調整のみ。

適用先は、戦闘の侵略クリーチャー選択前、未公開ウェポン、ウェポン公開時の拡大、ひらめきのカード飛翔、レア獲得メッセージ。
それぞれ表示サイズは用途に応じて変えるが縦横比は300:470を維持する。
レア獲得は同一画像3枚をCSSで重ねる。旧3枚重ね画像は現行表示では使用しない。

スマホの手札反転は進化後カードの表示なので、共通裏面に置き換えない。

実画面検証: `scripts/card_back_browser_test.cjs`。戦闘の公開順は `scripts/battle_presentation_browser_test.cjs` で確認。
