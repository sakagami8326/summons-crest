# カードレアリティ加工の適用範囲

2026-10-21 採用版：箔160%・虹色30%。レアリティ編集画面はローカル専用。

## 共通仕様

- `card-rarities.json` の保存済み84件を使用。現在 N 44 / R 26 / UR 14。
- 進化前後は同じレアリティ。
- N：加工なし。R：白い反射と星のきらめき。UR：承認された「箔・調整版」。微細な箔160%＋虹色30%。箔への照射から0.75秒遅れて虹色が速く通過。
- 加工はベージュ背景を含むカード全面。名前・コスト・能力文・AT/HP/DF・アイコンは加工より手前。
- 既存サイズ、縦横比、カードの裏返し演出は維持。
- 非表示・画面外の加工アニメーションは休止。prefers-reduced-motionに対応。

| スマホ | カード図鑑の一覧・詳細・進化切り替え |
| スマホ | ショップの商品カード・購入詳細 |
| スマホ | 召喚士選択の初期デッキ・カード拡大 |
| 盤面 | タイトル画面のカード群 |
| 盤面 | 戦闘の侵略側・防衛側クリーチャーカード |
| 盤面 | 公開ウェポンと支援クリーチャーのカード表面、公開時の拡大表示 |
| 盤面 | 召喚・スペル・回復報酬などが使うカード描画 |
| 盤面 | 外部効果・敵領地確認・スペル通知・鍛造報酬などの共通小型カード |

カードの裏面、盤上の駒、クリーチャー単体の立ち絵、過去記事に埋め込まれたスクリーンショットなどの静的資料は変更対象外。

## 検証

- `scripts/card_finish_browser_test.cjs`：保存済み全件とAPIの一致、スマホのN/R/UR・スペル・ウェポン、文字の重なり順、300:470の維持、加工の重複防止、盤面・公開前裏面・Shadow DOMの小型カード、ホームページ一覧・詳細・初期デッキ・トップ、390px表示、動きの軽減、JavaScript例外なし。
- `card_rarity_settings_test.js`：保存設定、進化後への継承、スペルのレアリティ別山札枚数、不正入力の拒否。
- 旧クリーチャー導入時の固定バランステストは `test_helpers/default-rarity-require.cjs` で当時の基準を保持し、ユーザー編集後のプロフィールは上記の専用テストで別途検証。
- pretest/testに含まれる回帰テストを分割実行。途中で見つかった固定レアリティ前提・関数抽出依存のテストを修正し、該当テストと後続を再実行して成功。
- 画面キャプチャとブラウザー検証結果：`output/card-finish-rollout/`。
