# 盤面の設定・音量

2026-09-28 通常ゲームへ組み込み。本番公開は別途。

## UI

左下「設定」から中央のダイアログを開く。最初はルームタブ（ルームコード/QR、保存終了、BOT戦のみ演出速度）。音声タブには全体ON/OFF、BGM・効果音の独立音量、各試聴、初期値へ戻すを配置。タブ切替時の外枠サイズを維持し、短い横画面では音量を2列にする。×/Esc/外側クリックで閉じ、元の設定ボタンへフォーカスを戻す。タイトル画面の設定入口は非表示。

## 音声

- `board-audio-settings.js` が音声初期化前に `sc_board_audio_v1` を読み込む。既定値はenabled=false、bgm=70、se=70。有限数だけ採用し0〜100へ丸める。不正JSON・保存不可でもゲーム進行は止めない。
- 100%は既存音源の基準音量。音源間の従来のバランスを保って係数を掛ける。OFFは全音源停止、音量値は保持。初期値へ戻す操作ではON/OFFを変更しない。
- BGMの曲切替・クロスフェード・戦闘決着の音量低下にも現在値を掛ける。BGM試聴は現在曲を使用するため別曲が二重再生されない。
- 通常SEはHTMLAudioのvolume、進化の溜め/衝撃とリザルトは独立した出力GainNodeで調整する。0%にしたときも後続の演出で音が戻らない。
- ON保存時でもブラウザの自動再生制約には従う。拒否された場合は音声タブに「音を有効にする」を表示し、操作によって再生を再試行する。
- スマホからの盤面音声の遠隔操作は含まない。既存のボタン操作へ新しい効果音は追加しない。
