# 新クリーチャー実装 引継ぎ (2026-08-11)

## 完了した内容

- バニホップ → ロードバンプ、ストラウク、サムライ・サガをv1.01として実装。
- 3種を市場山札へNレアリティとして登録し、カード・盤面・戦闘用アートを接続。
- バニホップのスペルカードダメージ無効、ロードバンプのスペル使用時100G収入(配置数ぶん重複)を実装。
- ストラウクとサムライ・サガが全属性土地から地形補正を得る処理を共通化。
- サムライ・サガの通常召喚・交代配置後に、土地属性変更または変更しない選択を追加。
- v1.01専用回帰テストを追加し、既存v1.00テストをv1.01でも実行可能に更新。

## 確定した挙動

- バニホップが防ぐのはスペルカードによる直接ダメージだけ。召喚士固有スキルは防がない。
- ロードバンプの収入はコスト0Gを含む正常なスペル使用ごとに発生し、配置中の個体数だけ加算する。
- サムライ・サガの属性選択は通常召喚と交代配置だけで発生する。侵略成功、進化、復元では発生しない。
- 「変更しない」を選んだ場合は、召喚前の土地属性を維持する。
- 全属性地形適応は既存の土地レベル×10の地形補正を使う。
