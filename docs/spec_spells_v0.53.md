# Summons Crest 追加スペル実装仕様 v0.53

## 1. 対象

本仕様は、以下の追加スペル13種を対象とする。

1. フレイム・シフト
2. 炎の渦
3. 血染めの刃
4. アクア・シフト
5. 満ち潮
6. 豊穣の角
7. アース・シフト
8. 岩盤隆起
9. 根の牢獄
10. ウィンド・シフト
11. 風向転換
12. 羽休め

## 2. 共通処理

- 通常のスペルと同様、自分の手番のダイスを振る前に使用する。
- 使用条件を満たす対象が存在しない場合は使用不可とする。
- コストを支払えない場合は使用不可とする。スペル使用によって所持金をマイナスにはできない。
- 「捨て札」と記載されたカードは解決後に捨て札へ置く。
- 「廃棄」と記載されたカードは解決後にゲームから除外する。
- 継続効果は、カード本体を捨て札へ移動した後もプレイヤーまたは土地に状態として保持する。
- 同名の継続効果は同じ対象に重複しない。再使用した場合は残り時間だけを更新する。
- スペルによる直接ダメージで残りHPが0以下になった場合、そのクリーチャーは撃破され、捨て札へ置く。ダメージを与えるすべてのスペルにこの処理を適用する。
- 「次の戦闘まで」の土地効果は、侵略が開始した時点で適用し、戦闘結果にかかわらず戦闘終了後に解除する。
- 土地に付与された継続効果は、その土地の所有者が変わっても指定された解除条件まで残る。
- 破産・脱落したプレイヤーが付与していたプレイヤー単位の継続効果は解除する。土地単位の効果は土地に残す。

## 3. 属性変更の共通仕様

フレイム・シフト、アクア・シフト、アース・シフト、ウィンド・シフトに適用する。

- 対象は、自分が所有する火・水・土・風の通常土地1つ。
- 城、祠、市場、門は対象外。
- 変更先と同じ属性の土地は対象外。
- 所有者、土地レベル、配置クリーチャー、進化状態、負傷、土地に付与された効果は維持する。
- 変更後、全プレイヤーの連鎖数、全土地の地価と通行料、総資産を即時再計算する。
- 配置クリーチャーが変更後の土地と同属性になった場合、次の戦闘から地形補正を得る。
- 無属性クリーチャーは通常どおり地形補正を得ない。クレオ系の適応は通常どおり有効。
- 属性変更そのものでは、召喚時能力やその他の配置時能力は発動しない。

### 4.2 炎の渦

| 項目 | 内容 |
|---|---|
| レアリティ | R |
| 共通山札枚数 | 2枚 |
| コスト | 50G |
| 使用後 | 捨て札 |
| 対象 | 敵が所有する通常土地1つ |
| 画像 | `c_sp_flame_vortex.png` |

効果：

1. 対象土地のクリーチャーに10ダメージを与える。残りHPが0以下になった場合、そのクリーチャーを撃破して捨て札へ置く。
2. 対象土地へ「炎の渦」状態を付与する。ダメージでクリーチャーが撃破された場合も、土地への「炎の渦」状態は残る。

4. 戦闘終了後に状態を解除する。

使用者以外が先に侵略した場合も、その攻撃側がAT+10を得る。

表示文：

> 敵領地に10ダメージを与える。次にその領地へ侵略するクリーチャーはAT+10。

| 項目 | 内容 |
|---|---|
| レアリティ | R |
| 共通山札枚数 | 2枚 |
| コスト | 40G |
| 使用後 | 捨て札 |
| 対象 | 対象選択なし。使用者に付与 |
| 画像 | `c_sp_bloodstained_blade.png` |

効果：

30Gの略奪はザーティーの略奪と加算する。支払い側は通常の支払い処理に従い、所持金がマイナスになった場合は土地売却・破産処理へ進む。

表示文：

### 4.5 満ち潮

| 項目 | 内容 |
|---|---|
| レアリティ | R |
| 共通山札枚数 | 2枚 |
| コスト | 50G |
| 使用後 | 捨て札 |
| 対象 | 自分が所有する水属性土地1つ |
| 画像 | `c_sp_high_tide.png` |

効果：

1. 対象土地へ「満ち潮」状態を付与する。
2. 対象土地で次に受け取る通行料を50%加算する。
3. 通行料を受け取った後に解除する。
4. 発動しなかった場合、使用者の次の手番開始時に解除する。

オルフェ系の清流とは加算式で処理する。

- 通常土地：基本通行料×1.5
- オルフェ系：基本通行料×（1+0.2+0.5）=基本通行料×1.7
- 最終値の小数点以下は既存の通行料処理と同じ方法で丸める。

侵略により通行料が発生しなかった場合は消費しない。防衛成功によって通行料が発生した場合は適用して消費する。

表示文：

> 選んだ水領地で次に受け取る通行料+50%。次の手番まで有効。

### 4.11 風の回廊（v1.04で廃止）

| 項目 | 内容 |
|---|---|
| レアリティ | R |
| 共通山札枚数 | 0枚（廃止） |
| コスト | 40G |
| 使用後 | 捨て札 |
| 対象 | 自分の通常土地1つと、その前後に隣接する通常土地1つ |
| 画像 | `c_sp_wind_corridor.png` |

この効果は「ムーブ」と役割が重複するため廃止し、市場・カタログ・操作UIから削除した。

対象条件：

- 移動元には自分のクリーチャーが配置されていること。
- 隣接は盤面番号の前後1マス。0と27も隣接する。
- 城、祠、市場、門には移動できない。
- 自分の領地には移動できない。
- 空き地または敵領地だけを移動先にできる。

空き地へ移動した場合：

1. 移動元を空き地にし、土地レベルをLv1へ戻す。
2. 移動先を使用者の領地として取得する。
3. 移動先の土地レベルはLv1。
4. クリーチャーの進化状態と負傷を維持する。
5. 召喚コストは支払わない。
6. 召喚時能力は発動しない。

敵領地へ移動した場合：

1. スペル解決時点で移動元を空き地にし、Lv1へ戻す。
2. 移動したクリーチャーを攻撃側として通常の侵略処理を開始する。
3. 双方は通常どおり支援カードを選択できる。
4. 侵略開始時の通行料支払いは発生しない。
5. 侵略成功時は通常どおり移動先を取得し、土地レベルを維持する。
6. 侵略成功時の1枚ドロー、称号、固有能力は通常どおり処理する。
7. 防衛成功時は通常どおり反撃する。
8. 攻撃側が生存した場合は全快して手札へ戻る。倒された場合は捨て札へ置く。ガストン系は固有能力を通常どおり適用する。
9. 侵略失敗時の通行料は支払わない。

表示文：

> 自分の領地のクリーチャーを隣接する土地へ移動する。敵領地なら侵略する。

### 4.12 風向転換

| 項目 | 内容 |
|---|---|
| レアリティ | R |
| 共通山札枚数 | 2枚 |
| コスト | 30G |
| 使用後 | 捨て札 |
| 対象 | 対象選択なし。使用者に付与 |
| 画像 | `c_sp_wind_shift.png` |

効果：

1. このターンの通常ダイス移動だけ、使用者の進行方向を逆にする。
2. ターン終了時に本来の進行方向へ戻す。
3. 城・門を通過した場合は通常どおり通過処理を行う。
4. 祠・市場などは、通常どおり停止した場合のみマス効果を処理する。
5. 疾風、レダーニULTなど複数ダイスによる移動にも適用する。
6. ミオULTなど「好きなマスへ移動する」効果には影響しない。

同じターンに複数回使用できない。

表示文：

> このターンだけ、通常とは逆方向へ移動する。

| 項目 | 内容 |
|---|---|
| レアリティ | N |

| コスト | 20G |
| 使用後 | 捨て札 |
| 対象 | 自分が所有する通常土地1つ |
| 画像 | `c_sp_feather_rest.png` |

効果：

1. 対象土地のクリーチャーを手札へ戻す。
2. 戻ったクリーチャーの負傷をすべて回復する。
3. 進化状態は維持する。

表示文：

> 自分の領地のクリーチャーを全回復して手札へ戻す。土地は空き地になる。

## 5. 戦闘補正の計算順

追加カードを含む戦闘時の推奨計算順は以下とする。

### 攻撃側AT

1. クリーチャーの基礎ATまたは進化後AT
2. クリーチャー固有能力（猛攻、群れなど）
3. プレイヤー継続効果（血染めの刃など）
4. 土地継続効果（炎の渦、根の牢獄など）
5. 支援カード
6. 最低0へ補正

### 防衛側DF

1. 地形補正
2. クリーチャー固有能力（岩壁など）
3. 隣接効果（女王の威光など）
4. 土地継続効果（岩盤隆起など）
5. 支援カード

呪具で無効になるのは支援カードだけとし、スペルによる継続効果は無効化しない。

## 9. 最低限必要な状態データ案

```js
// 土地単位
領地.状態 = {
  '炎の渦': false,
  '満ち潮': null,
  '岩盤隆起': false,
  '根の牢獄': false,
};

// プレイヤー単位
プレイヤー.状態 = {
  '血染めの刃': null,
  '風向転換': false,
};
```

セーブ・再接続・画面更新後も継続効果が失われないよう、これらはクライアント側だけでなくルーム状態としてサーバーに保持する。
