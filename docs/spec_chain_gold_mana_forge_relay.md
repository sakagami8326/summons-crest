# 追加カード3枚とチェンジの仕様整理

更新：2026-10-25。新カード3枚を通常ゲームへ実装。チェンジの手札返却は既存処理を修正。

## チェインゴールド

- スペル、0G、N。
- 使用時の自分の最大連鎖数×100Gを獲得。上限なし。
- 所有領地がない場合は使用不可。
- 連鎖は既存ルールと同じく土地属性ごとの所有数。クリーチャー属性や隣接は問わない。

## マナフォージ

- スペル、70G、R。
- 前案の「手札のクリーチャー1枚を廃棄」を維持。
- ソードとシールドを各1枚、自分の山札へ加えてシャッフルする。
- 生成した2枚を直接手札には加えない。

## 鬼継ノ太刀（オニツギノタチ）

- 外観は既存の `public/assets/c_jaki.png` の背負い剣をそのまま基準にする。
- 黒い岩状の大きな刀身、橙の亀裂と紋章、柄に付いた金の鎖を残す。
- 別の槍・バトン・角笛へ変更しない。
- 正式名称は「鬼継ノ太刀」。読みは「オニツギノタチ」。
- 侵略・防衛の両方で、勝利したクリーチャーに交代の選択権を与える。
- 手札の別のクリーチャーの召喚費用を支払って、勝利した領地へ配置する。
- 交代しない選択も可能。交代元は手札へ戻す。
- 交代時の土地Lvと土地属性は維持。新しい個体は全快で、旧個体の負傷・蓄積DF等を引き継がない。
- 新しく配置したクリーチャーの配置時能力を適用する。
- ディスアームや雲隠れでウェポンが無効になると、AT＋10と交代効果も無効。
- ジャキ自身の能力と重なっても、同じ勝利で交代できるのは1回。
- AT＋10を付与する。使用コスト80G、R。
- イラスト倍率は専用ビュアーで調整し、保存値を `output/imagegen/new-cards-20261025/viewer-settings.json` に記録する。

## 交代元の返却を統一

- ジャキ／アシュラカンの戦線交代、上記ウェポン、チェンジは、いずれも元のクリーチャーを手札へ戻す。
- 土地のレベルによる進化だけなら元のカードで返却。手札進化済みの `_f` カードは `_f` のまま返却する既存ルールを使用する。
- チェンジ自身は使用後に捨て札へ置く。
