# Summons Crest ─ ルール・仕様まとめ(v0.62)

実装(server.js)を正とした現行ルールの全体像。**このファイルは常に最新版を維持する**(ファイル名にバージョンを付けない)。
カード個別の詳細は `spec_creatures_v0.57.md` / `spec_spells_v0.53.md`、ドローの詳細は `spec_draw_v0.61.md`、セーブ/再開は `spec_save_v0.62.md`、遊び方の読み物は `manual.md` を参照。

## 1. ゲーム概要

- 2〜4人対戦の「すごろく×デッキ構築」。テレビに共有ボード、各自スマホで操作。
- 盤面は28マスの周回コース(属性土地20 + 城1・門1・祠4・市場2)。
- **勝利条件**: 総資産8000G以上の状態で**城を通過**する。
  - 総資産 = 所持金 + 所有地の地価合計 + 称号(1つ500G) + 秘宝(1つ600G)
  - 7000G到達で「ラストスパート」演出(BGMも変化)。
  - 破産者が出て残り1人になった場合はその時点で勝利。

## 2. 手番の流れ

1. **手番開始**: 継続効果の解除処理(自分が掛けた衰弱の呪い・結界・満ち潮など)→ **選択ドロー**(v0.61: 山札から2枚見て1枚を手札へ、1枚を捨て札へ。候補は本人のスマホにだけ表示。**制限時間なし** ─ v0.63でタイムアウト廃止)。
   - 山札不足時は捨て札をシャッフルして補充。山札+捨て札の合計が1枚なら自動取得、0枚なら引かずに進行。
2. **呪文フェイズ**: 手札の呪文を唱えられる(**1ターンに1回まで** ─ v0.60)。固有スキル(ULT)もこのタイミング。
3. **ダイス**: 1個振って移動(疾風=2個、烈火の進軍=3個)。**初回の移動時のみ進行方向を選択**し、以後変更不可。風向転換はそのターンだけ逆走。
4. **マス解決**(下記3章)。
5. **手番終了**: 手札8枚以上なら7枚になるまで捨てる。所持金がマイナスの人は強制売却→破産判定。

## 3. マスの解決

| マス | 止まったとき |
|---|---|
| 空き地 | 手札のクリーチャーを召喚して領地化(コスト支払い)/見送り |
| 自領地 | 領地1つを強化できる(どの領地でも可) |
| 敵領地 | 通行料を払う or 手札のクリーチャーで侵略 |
| 城 | 領地強化(通過時は勝利判定・周回ボーナス) |
| 門 | 恩恵を選ぶ: 領地強化/カードを引く(3枚ドラフト)/鍛錬(手札進化 −150G)/何もしない |
| 祠 | +100G+3枚ドラフト(共通山札から3枚→1枚獲得して自分の山札へ・残りは共通山札の底へ)+参拝回数+1 |
| 市場 | 買い物(5章) |

### 刻印と周回(v0.59〜)

- **門を通過**(通過でよい)すると **+200G と刻印❖** を入手(刻印未所持のときのみ)。
- **城を通過**時、刻印を消費して一周ボーナス: **+200G + 所有地価合計の10% + 無料ドラフト + 自領地全クリーチャーの負傷-10回復**。
- 刻印がないまま城を通過するとボーナスなし(周回数p.lapは刻印に関わらず+1)。

## 4. 経済(v0.60の数値)

- **地価** = 100G × Lv倍率 × 連鎖倍率
  - Lv倍率: Lv1=1 / Lv2=2.5 / **Lv3=10** / **Lv4=36**
  - 連鎖倍率(同属性の所有領地数): 1つ=1.0 / 2=1.4 / 3=1.8 / 4=2.2 / 5以上=2.6
- **通行料** = 地価 × 25% × rate(清流オルフェ+0.2、満ち潮+0.5の加算式)
  - 連鎖なしの目安: Lv1=25G / Lv2=62G / **Lv3=250G / Lv4=900G**
- **強化費用**(1段ごと): Lv2=100G / **Lv3=450G / Lv4=950G**(Lv1→4累計1500G)
  - 自キャラと同属性の土地は**親和-20%**。
  - 城・門・自領地停止時の強化では、資金があれば複数レベル一気上げも可能(累計費用)。
- その他の定数: 初期所持金300G / 城ボーナス200G / 門ボーナス200G / 祠100G / 鍛錬150G / 忘却80G / 宝石80G / 市場ドロー100G。

## 5. 市場

- カードを引く(−100G、3枚公開から1枚ドラフト)
- 支援カード購入: 武器(AT+20)60G / 重武器(AT+40)120G / 盾(DF+20)60G / 大盾(DF+40)120G / 呪具(相手の支援を無効化)100G
- 宝石購入(−80G、**1回の来店で2個まで**)
- **秘宝交換**: 宝石5個→秘宝1つ(勝利点+600G資産)。交換するたび次の必要数が**+2個**(5→7→9…・プレイヤーごと)
- **忘却**: 80Gで手札か捨て札のカード1枚をゲームから廃棄(1来店1回)
- リンネイULT「水鏡の大商談」中は全品半額+宝石購入数制限なし

## 6. 戦闘(v0.57方式)

- **戦闘耐久値プール** = 現在HP + DF。攻撃はプールから減算し、0以下で撃破。
- 支援カードは両者が**秘密裏に同時出し**(使い切り。呪具は相手の支援を無効化)。
- **攻撃AT計算順**: 基礎/進化 → 固有 → 死影 → 血染めの刃 → 炎の渦 → 根の牢獄 → 支援 → 最低0。
- **DF計算順**: 地形(同属性+10、岩壁ベデベロは+20)→ 女王(重複せず最大のみ)→ 岩盤隆起 → 支援。
- 攻撃側が撃破できなければ防衛側が**反撃**(1回)。反撃を耐えた攻撃クリーチャーは全快して手札に帰還。
- 特殊: パカワタ【先制】=防衛時、反撃の代わりに先に1回攻撃 / アヴァランチ【双撃】=侵略時のみ同AT2連撃。
- 侵略成功で土地を奪取(レベル維持・負傷は引き継ぎ)。勝利数3以上で称号「覇者」の対象。
- 加護の結界・大地の大結界が張られた領地には侵略できない。

## 7. クリーチャー・進化

- 領地の**Lv3到達で盤上進化**(見た目・ステータスが進化形に)。レベルを下げられても仕様上は進化演出時のみ判定。
- **鍛錬**(門・150G): 手札のクリーチャーをその場で進化形(`_f`)にする。進化形はコスト同じ・ステ強化。
- 羽休め・風の回廊などで手札に戻る際、進化状態は維持される。
- 死影(ベルーフ): スペルダメージを受けるたびAT+10(最大+30)。土地にいる間持続、手札に戻ると解除。
- カード個別の性能・固有能力は `spec_creatures_v0.57.md` 参照。

## 9. 手札・山札

- 手札上限**7枚**(手番終了時に超過分を選んで捨てる。ドロー直後には捨てさせない)。
- 共通山札82枚: 市場クリーチャー16種34枚 + スペル22種48枚(レア度別枚数: N×3 / R×2 / L×1)。尽きたら補充。
- キャラごとの初期デッキ12枚+初期手札5枚。手番開始は**選択ドロー**(自分の山札2枚から1枚)。祠と戦闘勝利(攻守どちらでも勝者)は**3枚ドラフト**(共通山札から3枚→1枚獲得→自分の山札へ ─ v0.74)。ひらめきは**直接ドロー**。
- **獲得カードはすべて現在の山札へ**(v0.61): ドラフト(市場/城/門)・支援カード購入・フーゴルムの鍛冶 → 山札に加えてシャッフル(位置は非公開)。捨て札や手札へ直接入れない。

## 10. 破産・脱落

- 所持金がマイナスになったら、0以上になるまで領地を**強制売却(地価の70%)**。
- 売る土地がなくなっても負なら**破産=脱落**(観戦)。破産者にpendingを出さないこと(開発規約)。

## 11. 称号(奪い合い・資産+500G)

- **覇者**: 侵略戦闘の勝利3回以上(保持者超えで奪取)
- **大巡礼者**: 祠参拝4回以上(同上)

## 13. UI・演出の設計思想(必ず守る)

1. **絵文字をUIに出さない**(iconizeでアイコン画像化 or 自動除去)。雰囲気を損ない安っぽく見えるため。
2. **直接タップ**: 選択はボタン列でなく、カード・マスそのものをタップさせる(鍛錬・交代=カードタップ、土地選択=ミニマップタップ)。
3. **大型UIは全画面切替**: 空きスペースへの押し込み配置は禁止(マップ選択・カード選択は全画面オーバーレイ)。
4. **テレビで全部見せる**: 秘匿は手札とドラフト内容のみ。スペル・戦闘・刻印・連鎖などの出来事は必ず演出/メッセージで全員に伝える。
5. **マスに変化があったらズーム**: クリーチャー退場・進化などはそのマスにカメラズーム+**中央下**のメッセージウィンドウ。
6. **演出は直列**: 前の演出が完全に終わってから次を出す(cutBusy/バナーキュー)。TURN STARTも割り込まない。
7. スマホは**フロー配置**(HUD/メッセージ/手札が重ならない構造)。ui_testのレイアウト検査で担保。
8. 手札カードは**長押しで拡大**(効果全文の確認)。

## 15. v1.01 新クリーチャー仕様

| 名前 → 進化形 | 属性 | レアリティ | コスト | AT/HP → 進化 | 効果 |
|---|---|---|---:|---|---|
| バニホップ → ロードバンプ | 火 | N | 60G | 10/10 → 40/60 | 進化前はスペルカードによるダメージを受けない。進化後は自分がスペルを使うたび100Gを得る |
| ストラウク | 無 | N | 120G | 10/70 | どの属性の土地からでも通常の地形補正を得る |
| サムライ・サガ | 無 | N | 120G | 50/50 | どの属性の土地からでも通常の地形補正を得る。通常召喚・交代配置時、その土地を火・水・土・風のいずれかへ変更できる |

- 市場山札には進化前の3種をNの規定枚数で登録する。ロードバンプは市場へ直接入れない。
- バニホップの耐性対象は、カードとして使用されたスペルの直接ダメージのみ。召喚士固有スキルや戦闘ダメージは防がない。
- ロードバンプの収入は、スペルが正常に使用された時点で配置中の個体数だけ重複する。コスト0Gのスペルも対象。
- サムライ・サガの属性変更は「変更しない」を選択できる。侵略成功による配置、進化、セーブ復元では選択を発生させない。
- ストラウクとサムライ・サガの地形補正値は、土地レベルに基づく既存の地形補正と同じ。

## 16. v1.02 新クリーチャー仕様

| 名前 → 進化形 | 属性 | レアリティ | コスト | AT/HP → 進化 | 市場枚数 | 効果 |

- マーローはRレアリティの市場枚数規則に対する個別例外として3枚入れる。他のRカードは2枚のまま。
