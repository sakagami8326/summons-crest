# 操作性フィードバック対応

- カード選択画面に、総資産と区別した最新の所持Gを表示。獲得可能条件は変更しない。
- 操作可能なダイスを文字・ラベル・光で強調し、同じ要求のSSE更新ではボタンを作り直さない。
- 手札幅は維持。通常の12px間隔から、必要量に応じてカード幅の最大10%まで重ねる。描画アニメーションの変形前の幅で計算する。
- 盤面のBOT速度ボタンは既存API・boardTokenを使用し、オプション内の設定と同期。
- 強化レベル選択の `ul:back` は費用・手番を消費せず候補へ戻る。進入元をpending.whereに保持。`ul:cancel` は従来どおり行動終了。BOT評価から戻る選択肢を除外する。
- 終了時の専用BGMは盤面のみ。最後の戦闘が終了した後に1秒クロスフェードし、全順位共通でループする。

## 専用音源

`public/assets/bgm-result-v1.mp3` はユーザー提供の `E:/クレストサーキット/BGM/試合終了.mp3` を無加工でコピーした約83.16秒の曲。
SHA-256: `DCBF757AEE4735132A8F750BEECBE3AE2F400D8D9355C76D7A5236C651C36927`。
音量は通常BGMの0.35に対し0.25。以前の72秒の仮音源は不採用。`scripts/compose-result-bgm.py` は仮音源用のため、採用ファイルを上書きしない。
グラフ効果音は `public/result-graph-audio.js` のWeb Audio合成。進捗に合わせて220→1320Hzへ連続的に上昇する柔らかい音と、自然終了時の短いチャイム。細かい打音は鳴らさず、2本の発振器を継続して滑らかに音程を変える。停止・スキップ・説明待ち・ミュート・タブ非表示中には鳴らさない。再開時はその時点の音程から短いフェードインで復帰する。

グラフ音の試聴は確認ページの「グラフ音を確認」から再生する。
