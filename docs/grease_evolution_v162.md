# v1.62 グリース【進化の胎動】変更箇所

グリースのデッキコンセプトを「進化・戦線交代」とし、旧必殺技を【進化の胎動】へ置き換える。

| 対象 | 変更内容 |
|---|---|
| ルール・対象選択 | 手札と自分の領地から未進化クリーチャーを各1体まで選択。片方だけでも発動可能。確定前の取消は回数を消費しない |
| 効果解決 | 5秒のカットイン後に永続進化。1ゲーム1回・G消費なし。土地レベル・属性・負傷・既存状態を維持。手札に戻っても進化を維持 |
| 再検証・保存復帰 | 選択時のカードと対象が一致するか確定時・解決時に確認。選択中とカットイン中の保存復帰に対応 |
| スマホ | 手札・領地を分けたカード選択、選択状態、確定・取消、必殺技説明と専用カットイン |
| 共有盤面 | 専用カットイン、領地の進化カード提示とエフェクト。手札のカード名・画像は公開しない |
| カットイン画像 | `public/assets/ult_grease-evolution-v1.webp`。技名を画像内にも反映し、進化を示す金色の魔法演出に変更。説明欄を左下へ配置し技名との重なりを回避 |
| BOT | 手札・領地それぞれの進化による戦力向上を評価し、対象選択から確定まで対応 |
| 紹介・説明文 | 召喚士選択、初期デッキ説明、公式ホームページ、説明書、仕様書を更新 |
| バージョン | サーバー・盤面・パッケージ・公式ページを1.62に統一 |

進化済み手札・永続進化済み領地・Lv3以上で進化している領地・相手領地は選択対象外。
進化によるクリーチャー固有能力の変化は通常の進化ルールに従う。召喚やスペル使用としては扱わない。

初期デッキはノーム3・ジャキ2・クレオ1・ゴールド1・ダブルドロー1・エヴォルヴ1・シールド2・ディスアーム1。
