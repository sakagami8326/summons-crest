# スミノコ → クロムクロ

2026-10-18承認仕様。v1.69ローカル実装。コミット・公開は別途。

| 項目 | スミノコ | クロムクロ |
|---|---|---|
| ID | suminoko | suminoko_f |
| 属性・レアリティ | 火・R | 火・R |
| AT / HP | 10 / 50 | 20 / 70 |
| 召喚コスト | 85G | 100G |
| 炭鎧の成長 | 防衛後DF +5 | 防衛後DF +10 |

防衛して生き残った戦闘の終了後に1回発動し、蓄積DFは次の戦闘から有効。上限なし。ダメージ0でも発動、双撃でも1戦闘1回。スペル被弾・通行料だけでは増えない。

配置個体の `charcoalDf` に実際のDF量を保存。進化・ムーヴの空き地移動と侵略・土地交換で個体に追従し、進化後は以降の増加分だけ+10になる。帰還・交代・撃破で解除。他個体に付着した古い値は除去。旧セーブの未設定値は0。地形・ウェポンのDFとは別に加算し、移動侵略時にも既存の蓄積値を適用する。

進化後100Gは召喚コスト。進化時の既存料金は変更しない。共通山札・ショップに進化前2枚。初期デッキ追加なし。
