# Summons Crest ドロー・デッキ回転改善仕様 v0.61

## 1. 目的

現在の「毎ターン1枚ドロー」では山札の循環が遅く、ゲーム中に獲得したカードを使えるまでに時間がかかる。また、状況に合わないカードが手札へ入り続けることで、デッキを構築・調整している感覚が弱い。

本変更では以下を目的とする。

- 毎ターンに見るカード枚数を増やす
- 欲しいカードを選ぶ判断を作る
- 手札の増加量は従来どおり1枚に保つ
- ゲーム中に獲得したカードを現在の山札へ反映する
- 戦闘勝利・祠などの追加ドローは簡潔な1枚ドローのまま維持する

---

## 2. 通常ドローの変更

### 変更前

> 手番開始時、山札からカードを1枚引く。

### 変更後

> 手番開始時、山札からカードを2枚見る。そのうち1枚を選んで手札へ加え、選ばなかった1枚を捨て札へ置く。

本仕様書では、この処理を「選択ドロー」と呼ぶ。

### 処理順

1. 手番開始時、山札から2枚を取り出す。
2. 取り出した2枚を、そのプレイヤーのスマホだけに表示する。
3. プレイヤーが1枚をタップする。
4. 選んだカードを手札へ加える。
5. 選ばなかったカードを捨て札へ置く。
6. 選択画面を閉じ、通常のスペルフェイズへ進む。

- 手札の増加量は1枚。
- 選ばなかったカードは廃棄ではなく捨て札。
- 捨て札へ置いたカードは、山札補充後に再び引ける。
- カードを選ぶ順番以外に、カード効果・コスト・レアリティによる制限はない。

---

## 3. 山札が不足した場合

選択ドローでは、可能な限り2枚を揃えてから選択画面を表示する。

### 山札に2枚以上ある場合

- 通常どおり上から2枚を取り出す。

### 山札に1枚だけある場合

1. 残り1枚を取り出す。
2. 捨て札をシャッフルして新しい山札を作る。
3. 新しい山札からもう1枚を取り出す。
4. 2枚から1枚を選ぶ。

### 山札が0枚の場合

1. 捨て札をシャッフルして新しい山札を作る。
2. 新しい山札から2枚を取り出す。
3. 2枚から1枚を選ぶ。

### 山札と捨て札を合わせても1枚しかない場合

- その1枚を自動的に手札へ加える。
- 選択画面は表示しない。

### 山札と捨て札の両方が0枚の場合

- カードを引かずに処理を終了する。
- ゲーム進行を止めない。

選択画面に表示中の2枚は、一時的に山札・手札・捨て札のいずれにも属さない「選択中カード」としてサーバーで保持する。選択完了前に捨て札へ混ぜないこと。

---

## 4. 選択ドローを行うタイミング

選択ドローを行うのは、各プレイヤーの通常の手番開始時だけとする。

```text
手番開始
→ 選択ドロー
→ 手番開始時の継続効果解除・更新
→ スペルフェイズ
→ ULT
→ ダイス
→ マス解決
→ 手札上限処理
```

既存実装で継続効果解除をドローより先に行っている場合は、ゲーム結果へ影響しない範囲で既存順を維持してよい。ただし、選択ドローは必ずスペル使用・ULT・ダイスより前に完了させる。

---

## 5. 選択ドローに変更しないドロー

以下は従来どおり、山札の上から1枚を直接手札へ加える。

### 1枚ドローを維持するもの

- 祠に止まったときのドロー
- 侵略成功時の勝利ドロー
- 防衛成功時の勝利ドロー
- 門の恩恵「カードを引く」が別途1枚ドローとして実装されている場合
- その他、効果文に「カードを1枚引く」と書かれた効果

これらのドローでは、2枚の選択画面を表示しない。

### 複数枚ドローを維持するもの

- ダブルドロー：山札から2枚を直接手札へ加える
- その他、効果文に指定された枚数を引く効果

ダブルドローでは「2枚見て1枚選ぶ」を2回行わない。従来どおり2枚とも手札へ加える。

---

## 6. 追加ドロー時の山札補充

祠、戦闘勝利、ひらめきなどでカードを直接引く途中に山札が尽きた場合は、捨て札をシャッフルして新しい山札を作り、残り枚数を引く。

例：ひらめきで2枚引くとき、山札に1枚しかない場合。

```text
山札の残り1枚を手札へ加える
→ 捨て札をシャッフルして山札を補充
→ 新しい山札から1枚を手札へ加える
```

---

## 7. 獲得カードの行き先

ゲーム中に新しく獲得したカードは、すべて現在の山札へ加える。捨て札や手札へ直接加えない。

### 対象

- 市場で100Gを支払って行うドラフト
- 城通過ボーナスの無料ドラフト
- 門の恩恵による無料ドラフト
- 市場で購入した武器、重武器、盾、大盾、呪具
- フーゴルムの鍛冶で得た武器
- 今後追加される「新しいカードを得る」効果

### 対象外

以下は新規獲得ではなく、既存カードの移動として扱う。

- 使用したスペルや支援カードを捨て札へ置く
- 戦闘後にクリーチャーを手札・捨て札へ移す
- 羽休めでクリーチャーを手札へ戻す
- 交代で元のクリーチャーを捨て札へ置く
- 忘却でカードを廃棄する
- スイッチ・ムーブによる盤面上の移動

### 山札への追加方法

1. 獲得カードを現在の山札へ加える。
2. 山札をシャッフルする。
3. 獲得カードがどの位置へ入ったかはプレイヤーへ公開しない。

- 山札が0枚の場合は、獲得カードだけで新しい山札を作る。
- 同じ処理で複数枚を獲得した場合は、すべて加えてから1回だけシャッフルする。
- 市場で複数の商品を購入した場合は、購入ごとにシャッフルせず、市場を閉じるときに獲得カードをまとめて山札へ加え、1回だけシャッフルしてよい。
- 山札の残り枚数は更新するが、カードの並び順や獲得カードの位置は表示しない。

---

## 8. ドラフト処理

ドラフト候補の表示と選択方法は従来どおりとする。

1. 共通山札から3枚を候補として表示する。
2. プレイヤーが1枚を選ぶ、または「カードを加えない」を選ぶ。
3. 選んだカードを個人の山札へ加える。
4. 個人の山札をシャッフルする。
5. 選ばなかった候補カードの共通山札への戻し方は既存処理を維持する。

「カードを加えない」を選んだ場合、個人の山札は変更しない。

---

## 9. 手札上限

- 手札上限は従来どおり7枚。
- 選択ドローや追加ドローによって手札が8枚以上になっても、ドロー直後には捨てさせない。
- 手番終了時に7枚になるまで捨てる。
- 選択ドローの2枚を見た段階で、手札上限を理由に片方を選択不可にはしない。
- ひらめきや戦闘勝利で手札が増えた場合も同様。

本仕様では、7枚以下の手札から任意に1枚を捨てる「手札整理」は導入しない。必要になった場合は別仕様として検討する。

## 10. スマホUI

### 選択ドロー画面

- スマホ上へ2枚のカードを横並びで大きく表示する。
- 見出しは「手札に加えるカードを選んでください」。
- 各カードは通常の手札カードと同じアート、名前、コスト、効果を表示する。
- カード本体のタップで即決定する。
- 確認ボタンは表示しない。
- カード長押しで既存の拡大表示を利用できる。
- 選択完了後、選んだカードが手札へ入るアニメーションを表示する。
- 選ばなかったカードは捨て札へ送られる短い表示を行う。

### 二重操作防止

- 1回目のタップを受信した時点で両カードを操作不可にする。
- サーバー側でも選択済みフラグを確認し、二重送信を無視する。
- クライアント側の表示順ではなく、カードインスタンスを識別して選択を処理する。

### 時間切れ

- 選択時間は10秒を基準とする。
- 時間切れ時は2枚からランダムに1枚を手札へ加える。
- もう1枚は捨て札へ置く。
- 残り時間はスマホにのみ表示してよい。

## 11. テレビ表示と秘匿情報

- テレビには2枚のカード内容を表示しない。
- テレビには「○○がカードを選んでいます」とだけ表示する。
- 選んだカード名、選ばなかったカード名は公開しない。
- 通常ドローと同様、手札へ入ったカードは秘匿情報とする。
- ドラフト候補も従来どおり本人のスマホだけに表示する。

選択中もテレビの演出キューを妨げないこと。前の演出が残っている場合は、既存の直列演出ルールに従う。

## 12. カード追加アニメーション

### 目的

カードを引いたとき、処理だけが先に完了して手札枚数が突然増えると、プレイヤーは「何を引いたのか」「なぜ増えたのか」を認識できない。

手札または山札へカードが追加されるすべての処理で、追加元・追加先・追加されたカードを認識できるアニメーションを表示する。

### 共通原則

- カード追加は、手札配列や山札枚数の表示を更新するだけで終わらせない。
- データ更新後、必ず対応する追加アニメーションを再生する。
- アニメーション中は同じカードを選択・使用できない。
- アニメーション完了後に操作を解放する。
- 複数のカードが同時に追加される場合は、追加枚数とカード内容が分かるように順番に表示する。
- 既存の演出直列ルールに従い、別のバナー、カットイン、マスズームと重ねて再生しない。
- アニメーションによってゲーム状態の確定を遅らせない。サーバー上では先にカード移動を確定し、クライアントでは演出完了まで操作をロックする。

### 通常の選択ドロー

1. 山札から2枚が画面中央へ並んで現れる。
2. プレイヤーが1枚をタップする。
3. 選んだカードを0.2秒程度拡大し、金色または属性色の縁で強調する。
4. 選んだカードが手札エリアへ移動する。
5. 選ばなかったカードは暗くなり、捨て札方向へ移動する。
6. 手札へ入ったカードを新規カード位置で0.4〜0.6秒強調表示する。
7. 手札枚数表示を更新し、数字を一度だけ軽く拡大する。
8. 演出完了後、スペル・ULT・ダイス操作を解放する。

選択直後に画面を閉じて手札だけを突然増やす実装は禁止する。

### 祠・戦闘勝利などの1枚ドロー

1. 山札を表すカード裏面を画面中央または山札位置から出す。
2. カードを表向きにして、引いたカードのアート・名前・効果を表示する。
3. 0.6〜1.0秒静止し、内容を確認できるようにする。
4. カードを手札エリアへ移動する。
5. 手札内の追加位置を0.4〜0.6秒強調する。
6. 手札枚数表示を更新する。

カード名を読めない速度で即座に手札へ縮小しないこと。

### ひらめきなど複数枚ドロー

- 2枚を中央へ並べて同時に表向きにする。
- 2枚の内容を0.8〜1.2秒表示する。
- 左から順番に手札へ移動する。
- 手札枚数表示は最後にまとめて更新してよい。
- 3枚以上を引く効果が将来追加された場合は、最大3枚まで横並び。それ以上は複数回に分けて表示する。

### 獲得カードを山札へ加える場合

市場・城・門のドラフト、支援カード購入、フーゴルムの鍛冶などでは、カードは手札ではなく山札へ入る。

1. 獲得したカードを画面中央へ表向きで表示する。
2. 「山札に追加」のラベルを表示する。
3. カードを山札アイコンへ移動させる。
4. 山札アイコンを一度だけ発光または拡大する。
5. 山札枚数を更新する。
6. シャッフルを表す短いカード重なりアニメーションを表示する。

山札へ入るカードを、手札へ入ったように見せないこと。手札追加と山札追加では移動先とラベルを明確に変える。

### フーゴルムの鍛冶

1. フーゴルムの召喚演出を完了する。
2. 武器カードを中央へ表示する。
3. 「鍛冶で武器を獲得」のメッセージを表示する。
4. 武器カードを山札へ移動する。
5. 山札追加・シャッフル演出を行う。

召喚演出と武器獲得演出を同時に重ねない。

### 演出時間の目安

| 演出 | 推奨時間 |
|---|---:|
| 選択後のカード強調 | 0.2〜0.3秒 |
| 引いたカードの内容表示 | 0.6〜1.0秒 |
| カードの手札への移動 | 0.3〜0.5秒 |
| 新規手札カードの強調 | 0.4〜0.6秒 |
| 山札追加・シャッフル | 0.6〜1.0秒 |

一連の通常ドロー演出は、選択時間を除いて1.5秒前後を目標とする。演出を認識できる長さは確保するが、毎ターンのテンポを大きく損なわないこと。

### 操作とスキップ

- 通常の手番開始ドロー演出は初回タップで即スキップしない。
- アニメーション開始から0.5秒経過後は、画面タップで残りを短縮できる。
- 短縮した場合も、最終的な追加先と新規カード強調を最低0.2秒表示する。
- カード選択そのものはスキップできない。
- 時間切れによる自動選択でも同じ追加アニメーションを表示する。

### 再接続時

- サーバー上ですでに手札追加が完了しており、演出だけが未完了だった場合、再接続後に同じ演出を最初から繰り返す必要はない。
- 代わりに、追加されたカードを手札内で1秒間強調し、「手札に追加されました」と表示する。
- 選択自体が未完了の場合は、従来どおり同じ候補2枚を再表示する。

### テレビ側

- 通常ドローのカード内容はテレビに表示しない。
- テレビでは対象プレイヤーの手札枚数が増えるアニメーションだけを表示してよい。
- 表示例：「レダーニがカードを1枚引いた」
- 戦闘勝利、祠、ひらめきなどドロー理由は共有してよい。
- 引いたカード名とアートは本人のスマホだけに表示する。

## 13. 再接続・保存

選択ドロー中に接続が切れても、再接続後に同じ2枚を再表示する。

サーバーのルーム状態に以下を保持する。

```text
選択ドロー中のプレイヤー
候補カード2枚
選択済みかどうか
選択開始時刻
時間切れ時刻
```

- 再接続時に候補カードを引き直さない。
- ページ更新で候補カードの順番を変更しない。
- 選択完了前に次のスペル・ULT・ダイス操作を受け付けない。
- 破産・脱落したプレイヤーには選択ドローを発生させない。

---

## 14. ログ

秘匿情報を守るため、共有ログにはカード名を記録しない。

共有ログ例：

```text
レダーニがカードを1枚引いた。
リンネイが市場でカードを獲得した。
```

本人のスマホだけに表示するログでは、カード名を表示してよい。

```text
バーンゲッコーを手札に加えました。
選ばなかったムーブを捨て札へ送りました。
```

## 15. 実装上の共通関数

ドロー処理を以下の2系統に分ける。

### 選択ドロー

用途：通常の手番開始。

```text
2枚を確保
→ プレイヤーへ候補を提示
→ 1枚を手札
→ 1枚を捨て札
```

### 直接ドロー

用途：祠、戦闘勝利、ひらめき、その他カード効果。

```text
指定枚数を山札から手札へ直接加える
```

どちらも共通の「山札不足時に捨て札をシャッフルして補充する処理」を使用する。

## 17. 説明書向け表記

> 手番開始時、山札から2枚を確認し、1枚を手札へ加えます。選ばなかったカードは捨て札へ置きます。祠や戦闘勝利で引くカードは、これまでどおり山札から1枚引きます。市場、城、門などで新しく獲得したカードは自分の山札へ加わります。
