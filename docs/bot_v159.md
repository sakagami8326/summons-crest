# SUMMONS CODE v1.59 標準BOT

## 目的と変更範囲

堅実な標準BOTへ改善する。v1.58で追加した進路・買い物改善を引き継ぐ。マップ、施設、移動、報酬、カード性能は変更しない。難易度UI・新規API・公開状態・セーブ形式は追加しない。

実装は `bot-standard.js`、ルールの正は `server.js`。後者から純粋な `calculateBattle` と既存の評価・費用関数を注入する。BOTモジュールには実ゲームの変更・HTTP・タイマー関数を渡さない。

## 評価入力と判断

- `view` が公開盤面、公開された人数・カード枚数、所持金、位置、方向、門取得、合法候補を複製する。自分のカードは内容を使えるが山札順はソートして失わせる。
- 相手の手札・山札・捨て札・廃棄は枚数だけを保持する。秘密の支援選択は常に空にする。将来の商品・ドロー・ダイス乱数を参照しない。
- `choose` は選択IDと候補ごとの点数・理由を返す。候補情報はテスト専用で、ルーム・セーブ・公開ログに保存しない。
- 確定勝利を優先し、同評価では支出・カード消費が少ない候補、さらに同点では合法候補順。判断用の確率抽選は廃止し、ゲームの乱数と操作待ち時間だけを維持する。
- 通常ダイスでも確定勝利するなら、無駄な固定ダイスを使わない。スペル費用は勝利判定前に差し引く。

## 戦闘

実処理と予測が同じ数値計算を使う。先制、双撃、進化、負傷、擬態、地形、ウェポン、無効化、土領地数、影、廃棄枚数、継続効果を反映する。カード消費・勝敗後の処理は実行側に残す。

相手の支援は「なし」「公開カタログの最大AT」「最大DF」「打ち消し」で代表させる。クリーチャーウェポンが使える相手には、公開所持金で使用可能な最大AT・最大HPの候補も加える。重複は除去し、支援を出せる手札枚数がなければ「なし」だけを使う。評価は平均70%＋最悪30%で、所持確率・実測勝率を表す値ではない。

侵略は支援との組み合わせまで比較する。失敗時の通行料、反撃・支援のカード消費、移動元領地の喪失、破産リスクを含める。防衛でも資産維持と被害軽減を評価し、同じ結果なら支援を温存する。通常侵略に召喚費はかからず、費用0の判断には安全資金の下限を課さない。

## 経済・領地・カード

- 安全資金は最低150G、手札最安の召喚費＋100G、次の通常移動で避けられない通行料＋100Gの最大値。任意支出はこれを残す。確定勝利・確定破産回避の評価では例外を認める。
- 土地価値、現在HPとDF、土領地補正、属性一致、強化割引、配置能力、通行料と相手の到達可能性を評価する。強化では全合法土地・目標レベルを比較し、予算外ならキャンセルする。
- 相手の次の通常ダイスは各出目を均等に扱い、分岐で複数の着地点を選べる場合は均等配分する。これは露出の目安であり、実際の相手方針や通行料の確定収入ではない。
- 売却は途中の連鎖低下・売却価格を再計算して組み合わせを比較する。探索幅32で処理量を制限するため、全盤面で数学的な最適解を保証するものではない。
- `botCardNeedScore` を購入、無料獲得、廃棄、回収で共用する。購入だけに同系統2枚・ウェポン3枚・1訪問2枚の抑制を適用する。無料獲得では価値とスキップを比較する。

## スペル・必殺技・特殊能力

全24スペルを対象に、効果と費用と温存を比較する。対象が複数段階の行動は同じ組み合わせ評価を再利用する。回復収入、スペル耐性・軽減、死影、属性変更後の連鎖・土領地数、移動元の喪失、交代時の負傷・標解除を含める。

ダイスは1〜3個の実際の確率分布で評価する。移動予測は実際の接続、錨、方向反転、門・城報酬、城帰還回復と勝利を扱う。旧マップと洞窟の違いは維持する。ヴィラは追加移動後の通常ダイスも評価し、ミオは経路を通らない到着として評価する。

全8召喚士の必殺技を専用評価する。リンネイは未公開商品ではなく予算と補充需要、グリースは危険にさらされた領地、アーデルは実回復と防御、リーア・ネラシオは対象の組み合わせを見る。使用価値が低ければ温存する。

## 検証

`npm run test:v159` / `npm test` で実行する。

- 改善前の戦闘・BOTコードを `test/fixtures/` に検査用参照として固定。サーバーからは読み込まない。
- 全クリーチャー形態を攻撃側・防衛側に置き、代表的な相手、進化・未進化、支援、移動侵略で計算共通化前後の実ルームと予測を照合。
- 無駄な支援、救える防衛、勝算のない侵略、資金不足の強化、無効な回復、固定ダイスの勝利と費用、非公開情報の非参照、予測の無変更、移動報酬、セーブ再開、古い予約を検査。
- 両マップ×2〜4人×10乱数シードを変更前後で実行（各60試合、計120試合）。初期デッキを召喚士と揃え、8召喚士をローテーションする。全試合で合法選択と完走を確認し、失敗侵略・支援消費・買い物・外周・破産・処理時間を出力する。
- 同一シードでも判断が変わると乱数消費と試合展開が変わる。集計は動作傾向の比較であり、対人勝率の証明ではない。外周選択率のノルマは設けない。
